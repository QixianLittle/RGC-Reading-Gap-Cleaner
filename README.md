# RGC — Reading Gap Cleaner

一个用于 Audacity 的 Nyquist 插件，用来自动清理朗读录音中的非讲话间隙。

当前版本：**v0.5**

RGC 会先学习当前录音环境的底噪、人声响度和朗读停顿节奏，再据此判断哪些区域更可能是讲话间隙。

适用于单人、近讲、环境相对稳定的录音，例如有声书、朗读、旁白和播客。

## 下载

下载仓库中的：

`RGC_Reading_Gap_Cleaner_v0_5_Standalone_CN.ny`

这是独立的单文件插件，不依赖此前版本。

## 安装

在 Audacity 中打开：

`工具 → Nyquist 插件安装器`

选择 `.ny` 文件并安装。

如果安装后没有看到插件，可以在插件管理器中重新扫描并启用。

插件名称：

`RGC - 朗读间隙自动清理 v0.5`

## 使用方法

第一次使用需要进行三步校准。

### 1. 学习空白

选择约 **2–5 秒**完全没有讲话的录音，然后运行：

`1 学习空白`

这段样本应尽量只有当前麦克风和房间的正常底噪，不要包含明显的碰撞、键盘或鼠标声。

插件会据此估计当前环境的底噪分布。

### 2. 学习人声

选择约 **2–5 秒**自然朗读的一整句话，然后运行：

`2 学习人声`

不需要刻意连续发声。正常的词间停顿和短暂低谷可以保留。

插件会先利用第一步得到的底噪数据排除明显的非语音部分，再统计有效人声的响度范围。

### 3. 学习朗读节奏

选择约 **20–60 秒**平时状态下的自然朗读，然后运行：

`3 学习朗读节奏`

样本中可以正常包含词间停顿、逗号、换气和句间停顿。

插件会统计停顿时长，并尝试区分语言内部的短暂停顿和较长的讲话间隙。

### 4. 执行清理

完成前三步后，选择需要处理的音频，运行：

`4 执行清理`

建议首先使用：

- 清理强度：`标准`
- 空白中的短促孤立声音：`作为杂音处理`
- 清理后的空白电平：`数字静音`

如果处理结果不合适，可以撤销后更换清理强度重新运行。

## 清理强度

### 保守

更重视保护人声：

- 要求更长的空白才执行清理
- 人声前后保留更多时间
- 更谨慎地处理短促孤立声音

适合轻声较多、句尾较弱的录音。

### 标准

直接使用自动校准得到的参数。

建议优先使用这一档。

### 强力

更积极地清理间隙：

- 更短的停顿也可能被处理
- 人声前后保护范围更小
- 更容易把短促孤立声音并入空白

误删风险也会更高。

## 空白中的短促孤立声音

`作为杂音处理` 用于处理类似：

```text
讲话 ───── 空白 ── 啪 ── 空白 ───── 讲话
```

如果一个较短的响声前后都有足够长的安静区域，RGC 会倾向于把它视作空白中的孤立杂音。

这可以处理部分鼠标声、轻微碰桌、短促碰麦等声音。

如果录音中经常包含很短的“嗯”“啊”等语气词，可以改为：

`保留`

RGC 当前不进行语义识别，因此无法保证区分所有短语音和短促杂音。

## 清理后的空白电平

### 数字静音

将检测到的间隙降到数字零，相当于手动对这些区域执行静音。

### 降低 60 dB

不完全静音，而是在原有基础上大幅衰减。

### 降低 40 dB

保留更多原本的环境底噪。

如果数字静音导致讲话之间出现明显的环境声断层，可以尝试后两种模式。

## 查看校准状态

运行：

`5 查看校准状态`

可以查看当前保存的参数，包括：

- 空白 P50 / P95
- 人声 P25
- 有效语音占比
- 人声进入 / 退出阈值
- 人声与底噪分离度
- 微停顿 / 空白分界
- 最短可清理空白
- 人声前后保护时间
- 孤立声音长度上限

这些数据主要用于调试。

## 重置校准

运行：

`6 重置校准`

可以清除当前校准数据。

以下情况发生明显变化后建议重新校准：

- 更换麦克风
- 修改录音增益
- 改变与麦克风的距离
- 更换录音环境
- 环境底噪明显变化

## 工作原理

RGC v0.5 不使用语音识别模型。

当前实现主要基于：

- 10 ms 短时 RMS 分析
- 基于底噪样本的人声候选筛选
- 双阈值滞回
- 时间连续性判断
- 短低能量缺口填补
- 孤立短声音检测
- 人声起止区域保护
- 停顿时长统计
- 对数停顿时长双类聚类

三次校准分别估计：

```text
空白样本 → 当前录音环境有多响
人声样本 → 当前说话声音有多响
自然朗读 → 当前说话方式通常会停多久
```

最终的清理规则由这三组数据共同决定。

## 已知限制

RGC 当前仍然是基于响度和时间结构的启发式检测器，不是完整的 VAD 或语音识别系统。

以下情况可能出现误判：

- 极轻的句尾
- 很短的语气词
- 明显的咂嘴或呼吸声
- 较长的碰撞声
- 持续性的背景声音
- 人声与底噪响度非常接近
- 多人录音
- 录制过程中麦克风距离或增益变化明显

重要录音建议保留原始轨道。
