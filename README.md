# RGC — Reading Gap Cleaner

一个用于 Audacity 的 Nyquist 插件，用来自动清理朗读录音中的非讲话间隙。

当前版本：**v0.5**

RGC 会先用几段样本估计当前录音的：

- 环境底噪
- 人声响度范围
- 朗读中的停顿时长分布

然后据此判断哪些区域属于正常语音，哪些区域更可能是讲话之间的空白。

它主要用于单人、近讲、环境相对稳定的录音，例如有声书、朗读、旁白和播客。

## Install

在 Audacity 中打开：

`工具 → Nyquist 插件安装器`

选择 `.ny` 文件并安装。

如果安装完成后没有看到插件，可以在插件管理器中重新扫描并启用。

插件名称：

`RGC - 朗读间隙自动清理 v0.5`

---

## Usage

RGC 第一次使用需要进行三步校准。

### 1. 学习空白

选择约 **2–5 秒**没有讲话的录音。

运行：

`1 学习空白`

这里应当只有当前麦克风和房间的正常底噪。尽量不要包含碰桌子、键盘声等明显的瞬时声音。

插件会记录底噪的响度分布，主要用它确定后续人声检测的基准。

---

### 2. 学习人声

选择约 **2–5 秒**正常朗读的一整句话。

运行：

`2 学习人声`

不需要刻意连续发声。正常的词间停顿和短暂低谷可以保留。

这一阶段会先利用第一步得到的底噪数据排除明显的非语音部分，再统计有效人声的响度分布。

如果有效语音比例过低，插件会提示重新选择样本。

---

### 3. 学习朗读节奏

选择约 **20–60 秒**平时状态下的自然朗读。

运行：

`3 学习朗读节奏`

样本中最好正常包含：

- 词间停顿
- 逗号停顿
- 换气
- 句间停顿

RGC 会统计检测到的停顿长度，并尝试区分短暂的语言内部停顿和较长的讲话间隙。

这一步会自动生成后续清理所需的时间参数。

---

### 4. 执行清理

完成前三步后，选择需要处理的音频，然后运行：

`4 执行清理`

一般可以先使用：

- 清理强度：`标准`
- 空白中的短促孤立声音：`作为杂音处理`
- 清理后的空白电平：`数字静音`

处理结果不合适时，可以直接撤销后更换清理强度重新运行。

## Clean Strength

### 保守

减少误删的优先级更高。

会：

- 要求更长的空白才执行清理
- 扩大人声前后的保护范围
- 更谨慎地处理短促孤立声音

适合轻声较多、句尾较弱的录音。

### 标准

直接使用校准得到的参数。

建议首先尝试这一档。

### 强力

更积极地清理间隙。

会：

- 允许处理更短的空白
- 缩小人声前后的保护范围
- 更容易将短促孤立声音并入空白

误删风险也相应更高。

## Short isolated sounds

选项：

`空白中的短促孤立声音`

用于处理这种情况：

```text
讲话 ───── 长空白 ── 啪 ── 长空白 ───── 讲话
如果选择：

作为杂音处理

当一个较短的响声前后都有足够长的安静区域时，RGC 会倾向于将它视为空白中的孤立杂音，而不是一次新的讲话。

这可以处理部分：

鼠标声
轻微碰桌
很短的碰麦声
其他瞬时杂音

如果录音中经常有很短的“嗯”“啊”等语气词，可以改为：

保留

RGC 目前并不进行语义识别，因此无法保证区分所有短语音和短促杂音。

Output level
数字静音

检测到的间隙会被降到数字零。

相当于手动选中这些区域后执行静音。

降低 60 dB

不完全静音，而是在原有基础上大幅衰减。

降低 40 dB

保留更多原本的环境底噪。

如果数字静音导致讲话之间出现明显的环境声断层，可以尝试后两种模式。

更换录音环境
环境底噪明显变化
How it works

RGC v0.5 不使用语音识别模型。

当前实现主要基于：

10 ms 短时 RMS 分析
基于底噪样本的人声候选筛选
双阈值滞回
时间连续性判断
短低能量缺口填补
孤立短声音检测
人声起止区域保护
停顿时长统计
对数停顿时长的双类聚类

三次校准分别解决不同的问题：

空白样本
→ 当前录音环境有多响

人声样本
→ 当前说话声音有多响

自然朗读样本
→ 当前说话方式通常会停多久

最终的清理规则由这三组数据共同决定。

Limitations

RGC 当前仍然是基于响度和时间结构的启发式检测器，不是完整的 VAD 或语音识别系统。

以下情况可能出现误判：

极轻的句尾
很短的语气词
明显的咂嘴或呼吸声
较长的碰撞声
持续性的背景声音
人声与底噪响度非常接近
多人录音
麦克风距离或增益在录制过程中变化很大

建议在重要录音上保留原始轨道，并使用 Audacity 的撤销功能检查处理结果。
