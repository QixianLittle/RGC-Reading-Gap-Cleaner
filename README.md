# RGC — Reading Gap Cleaner

一个用于 Audacity 的 Nyquist 插件，用来自动清理朗读录音中的非讲话间隙。

当前版本：**v0.5**

RGC 会先用几段样本估计当前录音的：

- 环境底噪
- 人声响度范围
- 朗读中的停顿时长分布

然后据此判断哪些区域属于正常语音，哪些区域更可能是讲话之间的空白。

它主要用于单人、近讲、环境相对稳定的录音，例如有声书、朗读、旁白和播客。

## Install

在 Audacity 中打开：

`工具 → Nyquist 插件安装器`

选择 `.ny` 文件并安装。

如果安装完成后没有看到插件，可以在插件管理器中重新扫描并启用。

插件名称：

`RGC - 朗读间隙自动清理 v0.5`

---

## Usage

RGC 第一次使用需要进行三步校准。

### 1. 学习空白

选择约 **2–5 秒**没有讲话的录音。

运行：

`1 学习空白`

这里应当只有当前麦克风和房间的正常底噪。尽量不要包含碰桌子、键盘声等明显的瞬时声音。

插件会记录底噪的响度分布，主要用它确定后续人声检测的基准。

---

### 2. 学习人声

选择约 **2–5 秒**正常朗读的一整句话。

运行：

`2 学习人声`

不需要刻意连续发声。正常的词间停顿和短暂低谷可以保留。

这一阶段会先利用第一步得到的底噪数据排除明显的非语音部分，再统计有效人声的响度分布。

如果有效语音比例过低，插件会提示重新选择样本。

---

### 3. 学习朗读节奏

选择约 **20–60 秒**平时状态下的自然朗读。

运行：

`3 学习朗读节奏`

样本中最好正常包含：

- 词间停顿
- 逗号停顿
- 换气
- 句间停顿

RGC 会统计检测到的停顿长度，并尝试区分短暂的语言内部停顿和较长的讲话间隙。

这一步会自动生成后续清理所需的时间参数。

---

### 4. 执行清理

完成前三步后，选择需要处理的音频，然后运行：

`4 执行清理`

一般可以先使用：

- 清理强度：`标准`
- 空白中的短促孤立声音：`作为杂音处理`
- 清理后的空白电平：`数字静音`

处理结果不合适时，可以直接撤销后更换清理强度重新运行。

---

## Clean Strength

### 保守

减少误删的优先级更高。

会：

- 要求更长的空白才执行清理
- 扩大人声前后的保护范围
- 更谨慎地处理短促孤立声音

适合轻声较多、句尾较弱的录音。

### 标准

直接使用校准得到的参数。

建议首先尝试这一档。

### 强力

更积极地清理间隙。

会：

- 允许处理更短的空白
- 缩小人声前后的保护范围
- 更容易将短促孤立声音并入空白

误删风险也相应更高。
